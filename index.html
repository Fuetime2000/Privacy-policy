1. Introduction

Welcome to Lairy ("we," "our," or "us"). Lairy is an AI-powered personal assistant application designed to enhance productivity, improve accessibility, and provide safety features through voice commands, automated transaction tracking, and intelligent assistance.

This Privacy Policy explains how Lairy collects, uses, stores, and protects your personal information. By using Lairy, you agree to the practices described in this policy.

Our Commitment:

  • ✅ 100% Local Processing - All data is stored and processed locally on your device
  • ✅ No Cloud Storage - We do not upload your data to external servers
  • ✅ No Data Selling - We never sell, rent, or trade your personal information
  • ✅ User Control - You have complete control over your data
  • ✅ Transparency - We clearly explain what data we collect and why

2. Age Restriction

Lairy is NOT intended for use by children under 13 years of age.

3. Information We Collect

Lairy collects information ONLY to provide its core functionality. All data is stored locally on your device and is never transmitted to external servers.

3.1 Voice Data

Category Details
What We Collect Voice commands and audio recordings for voice recognition, wake word detection data ("Hey Lairy"), voice-to-text transcriptions
Purpose Enable hands-free voice control, execute voice commands (open apps, make calls, set alarms), provide voice-activated assistance
Storage Processed locally using on-device speech recognition, temporary audio buffers deleted after processing, no voice data sent to external servers

3.2 SMS Messages

Category Details
What We Collect Bank transaction SMS messages, sender information (bank names, short codes), transaction details (amount, date, balance)
Purpose Automatic transaction tracking for business/personal finance, generate expense reports and analytics, track income and expenses
Storage Stored locally in encrypted SQLite database, only transaction-related SMS are processed, original SMS remain in your phone's message app, no SMS data shared with third parties

3.3 Call Information

Category Details
What We Collect Call recordings (when feature is enabled), phone numbers and contact names, call duration and timestamps, call direction (incoming/outgoing)
Purpose Call recording for personal record-keeping, business call documentation, call history and analytics
Storage Recordings stored locally in device storage, encrypted database for call metadata, user can delete recordings anytime, no call data transmitted externally

3.4 Location Data

Category Details
What We Collect GPS coordinates (latitude, longitude), location accuracy and altitude, address information (city, country), movement patterns and activity type
Purpose Safety features (fall detection, emergency alerts), lost mode device tracking, location history for personal tracking, geofencing and location-based reminders
Storage Stored locally in encrypted database, location history retained per user settings, no location data sent to external servers, user can clear location history anytime

3.5 Contacts

Category Details
What We Collect Contact names and phone numbers, contact associations for calls and messages
Purpose Display contact names in call recordings, voice-activated calling ("Call John"), enhanced user experience
Storage Read-only access to device contacts, no contacts stored separately by Lairy, no contacts uploaded to external servers

3.6 Device Information

Category Details
What We Collect Device model and Android version, app version and build number, battery level and charging status, network connectivity status, installed apps list (for voice commands)
Purpose App functionality and compatibility, voice command app launching, battery optimization, service reliability
Storage Minimal device info stored locally, used only for app operation, no device fingerprinting, no tracking across devices

3.7 Photos and Media

Category Details
What We Collect Access to photos, videos, and documents, media files for sharing and processing
Purpose Share files via voice commands, PDF viewing and document management, media playback control
Storage Read-only access to media, no media files copied or uploaded, user controls all file access

3.8 Accessibility Data

Category Details
What We Collect Current app in foreground, screen content for app detection, UI interaction events
Purpose Voice-activated app switching, context-aware voice commands, enhanced accessibility features
Storage Processed in real-time, no screen content stored, no accessibility data logged

5. Data Storage and Security

5.1 Local Storage

All data is stored locally on your device:

  • ✅ Encrypted SQLite database for sensitive data
  • ✅ Secure file storage for recordings and media
  • ✅ Android Keystore for encryption keys
  • ✅ Biometric authentication protection

5.2 Encryption

Data Protection Measures:

  • At Rest: All sensitive data encrypted using AES-256
  • Database: SQLCipher for encrypted database storage
  • Files: Encrypted file storage for recordings
  • Keys: Secure key management using Android Keystore

5.3 No Cloud Storage

We Do NOT:

  • ❌ Upload your data to cloud servers
  • ❌ Sync data across devices
  • ❌ Store data on external servers
  • ❌ Create backups on our servers

You Control:

  • ✅ All data stays on your device
  • ✅ You can export data locally
  • ✅ You can delete all data anytime
  • ✅ Uninstalling removes all app data

5.4 Backup

Android Backup:

  • App supports Android's built-in backup
  • Backups encrypted by Android OS
  • Stored in your Google Drive (if enabled)

Manual Export:
